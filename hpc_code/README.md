# Simulation code as run on the high-performance computing (HPC) cluster

This folder holds `sqec.zip`. The archive contains the simulation code exactly as it ran on the HPC cluster to produce the data in `../data/`.

- We provide the archive as-is, for transparency.
- We do not maintain this code. We do not give support for it.
- You do not need this code to make the figures. `../Paper_plots.ipynb` uses only the CSV files in `../data/`.

To look at the code, extract the archive:

```
unzip sqec.zip
```
